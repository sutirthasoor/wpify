Import a published Canva Website into WordPress as editable Gutenberg, Elementor or Bricks pages.

== Usage ==
1. Canva: Share > Website > Publish. Copy the *.my.canva.site link.
2. WordPress: WPIFY > paste link > Scan pages.
3. Tick pages (or "Import first N"), choose editor, Import.

== Notes ==
* Only published Canva Websites expose real text/images/structure. A plain canva.com/design link yields a preview image only.
* Layout is rebuilt as stacked sections (heading, text, image, button, list); Canva's free-form positioning and animations are not replicated.
* Images are copied to the Media Library. SVG falls back to the Canva URL unless your site allows SVG uploads.
* Only import designs you own or have rights to.
